
# 창원시 전기차 스마트 충전소 추천 시스템

## 프로젝트 목적
전기차 충전 수요가 특정 지역에 집중되는 문제를 완화하기 위해 충전소를 추천하고 수요 분산을 지원한다.

## 주요 기능
- 차량 SOC 및 배터리 용량 입력
- 충전시간 추정
- 충전소별 예상 이동시간 및 대기시간 비교
- 충전소 추천
- 충전기 이용률 시뮬레이션

## 데이터 안내
현재 충전소 정보는 교육용 예시 데이터다.
실제 운영 서비스에는 공공 충전소 API와 검증된 데이터를 연결해야 한다.

팀장: 임승현
